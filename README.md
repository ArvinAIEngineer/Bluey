# 🐕 Bluey's Backyard Games

A fun browser-based 3D game for kids featuring Bluey and Bingo!

## Games

- **Bluey's Biscuit Run** — Run around the backyard collecting 12 biscuits in 60 seconds!
- **Bingo's Flower Hunt** — Help Bingo collect all the flowers before time runs out!

## Deploy to Vercel

1. Push this folder to a GitHub repo
2. Go to [vercel.com](https://vercel.com) → New Project → Import your repo
3. Leave all settings as default (it's a static site)
4. Click Deploy — done! ✅

## File Structure

```
/
├── index.html          ← Home page (character select)
├── bluey.html          ← Bluey's Biscuit Run
├── bingo.html          ← Bingo's Flower Hunt
├── BlueyMinifig.glb    ← Bluey 3D model
└── bingo.glb           ← Bingo 3D model
```

## Controls

- **W A S D** or Arrow Keys to move
- Collect all items before the timer runs out!
